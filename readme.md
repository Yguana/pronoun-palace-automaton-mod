# HOW TO INSTALL

This mod requires the [Pronoun Palace Mod Framework](https://github.com/Emarald64/pronoun-palace-framework) by [Xanderath](https://github.com/Emarald64) to properly function.

To use these mods in a compiled (normal) version of the game, download the **RELEASE VERSION** of both mods. Then, create a folder named ``/mods/`` in the folder containing the game's local files. 
Extract the content of both zips, and place them inside the mod folder like this:
-  ``mods/framework``
-  ``mods/automaton_character``

To use/modify/add to these mods, through the Godot editor, you will need a decompiled version of the game and the **SOURCE CODE** of both mods, organized in the ``/mods/`` folders the same way as a compiled version of the game.

# MOD COMPATIBILITY

This mod has easy pluggable methods which allow for easy linking with other mods. Refer to ``misc/mod_compatibility/compatibility_reference.gd`` for more info on how to add compatibility.
